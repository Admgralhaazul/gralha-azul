Como colocar os dados COMPLETOS no Lovable

Não peça ao chat do Lovable para “colar a planilha” — ele corta e fica incompleto. O jeito certo é o script abaixo, que baixa as 1953 linhas já importadas.

Por que ficou incompleto?
  • O chat do Lovable resume / trunca arquivos grandes
  • Ele não lê as 1953 linhas linha a linha
  • Só o script de carga grava o JSON completo na nuvem

Passo a passo (5 minutos)

  1. Abra o sistema já logada:
    https://gralha-azul.lovable.app/sistema?modulo=sistema
  2. Espere aparecer o dashboard (não só “Carregando…”).
  3. Pressione F12 (ou Ctrl+Shift+J) → aba Console.
  4. Se existir um seletor de contexto no topo do console, escolha o frame sistema.html (não “top”).
  5. Volte nesta página, clique em Copiar script, cole no Console e aperte Enter.
  6. Deve aparecer um alerta com:
    • Ocupados: 1264
    • Assistente: 144
    • Executadas pela Imob: 591 (condomínios juntos)
  7. No sistema, abra cada módulo e confira os totais. Se bater, está na nuvem.
